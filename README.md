# EmberRift

EmberRift is a distributed, parallel processing platform that enables real-time data aggregation and auto-scaling across a scalable framework.

EmberRift is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/EmberRift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
